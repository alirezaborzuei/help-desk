# Help Desk

A React-based **Help Desk / Ticket Management** application for managing support requests and tracking their workflow.

## Overview

The project provides a frontend foundation for a help-desk system, including application routing and a structure that can be extended with authentication, ticket management, users, and reporting.

## Tech Stack

- React
- React Router
- JavaScript
- Create React App

## Getting Started

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm start
```

The application runs locally at `http://localhost:3000`.

### Build for production

```bash
npm run build
```
